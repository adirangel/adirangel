## 🤖 My AI-Augmented Pipeline

Every stage of my workflow has an AI copilot wired into it — from writing the pipeline to explaining why the cluster is on fire:

```mermaid
flowchart LR
    subgraph AILAYER["🤖 AI Copilots"]
        direction LR
        CL(["Claude Code"])
        CP(["GitHub Copilot"])
        GPT(["ChatGPT"])
        GR(["Grok"])
        KG(["k8sgpt"])
    end

    DEV["💻 Code & Config"] --> CI["🔧 CI<br/>Jenkins · Azure DevOps"]
    CI --> ART["📦 Artifacts<br/>JFrog · Nexus · Harbor"]
    ART --> CD["🚀 Deploy<br/>K8s · OpenShift · RKE2<br/>Rancher · Helm"]
    CD --> MON["📡 Monitor<br/>Zabbix · Prometheus<br/>Grafana · Splunk"]
    MON -- feedback --> DEV

    CL -.-> DEV
    CP -.-> DEV
    GPT -.-> CI
    GR -.-> MON
    KG -. "explains cluster errors" .-> CD
```
